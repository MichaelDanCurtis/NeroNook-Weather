# Weather Observatory plugin
Keep this an independent package. The host uses only the generic SDK and runs without plugins. The owned Observatory adapters are reused under Worker/observatory, with provenance in README. Bundle every runtime and web asset; no system Node, running website, browser login or external desktop app requirement. Never import site or Google secrets. Source validity, fetch age, model estimates, stale cache and unavailable feeds must remain distinct. Keep 16:9 module diagrams plus one status line, selected-location timezone/units, and independent feed errors. No automatic geolocation. Test normalizers, bounds, cache/error handling and native installation/live behavior. Do not claim all Observatory features or commercial-release readiness from this first slice.
